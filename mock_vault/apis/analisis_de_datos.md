# ¿Qué es necesario para aprender Análisis de Datos?

El análisis de datos es una disciplina multidisciplinaria que combina matemáticas, estadística, programación y conocimiento de negocio para extraer información útil y accionable a partir de datos en bruto. 

Si quieres aprender análisis de datos desde cero, aquí tienes los pilares fundamentales que necesitas dominar:

---

## 1. Fundamentos Matemáticos y Estadísticos
No necesitas ser un doctor en matemáticas, pero sí comprender los conceptos básicos que sustentan el análisis:
* **Estadística descriptiva:** Media, mediana, moda, desviación estándar, varianza, distribuciones de probabilidad.
* **Estadística inferencial:** Pruebas de hipótesis, intervalos de confianza, p-valores.
* **Álgebra lineal básica:** Conceptos de matrices y vectores (muy útiles si avanzas hacia Machine Learning).

## 2. Herramientas y Programación
El análisis moderno requiere el uso de lenguajes y software especializado:
* **SQL (Structured Query Language):** Es **imprescindible**. La gran mayoría de los datos de las empresas viven en bases de datos relacionales, y saber hacer consultas (`SELECT`, `JOIN`, `GROUP BY`, subconsultas) es la habilidad técnica más demandada.
* **Python o R:** 
  * **Python** es el lenguaje rey actualmente por su versatilidad y comunidad. Debes aprender librerías clave como:
    * `Pandas` y `NumPy` para manipulación y limpieza de datos.
    * `Matplotlib` y `Seaborn` para visualización de datos.
* **Excel / Google Sheets:** Aunque parezca básico, sigue siendo la herramienta más utilizada en el mundo empresarial para análisis rápidos y reportes ad-hoc. Conviene dominar tablas dinámicas, buscarV/BUSCARX y funciones lógicas.

## 3. Visualización y Storytelling (Creación de Dashboards)
Los datos no sirven de nada si no se pueden comunicar de forma efectiva a los tomadores de decisiones:
* **Herramientas de Business Intelligence (BI):** Aprende al menos una de las grandes herramientas de mercado:
  * **Power BI** (de Microsoft)
  * **Tableau**
* **Principios de diseño visual:** Saber qué gráfico elegir (barras, líneas, dispersión, mapas) según el tipo de dato y la historia que quieres contar.

## 4. Conocimiento de Negocio (Business Acumen)
Un buen analista no solo procesa números, sino que entiende *para qué* lo hace:
* Entender los objetivos de la empresa u organización.
* Saber formular las preguntas correctas (hacer *data-driven questions*).
* Traducir los hallazgos técnicos en recomendaciones estratégicas para el negocio.

---

## Ruta de aprendizaje sugerida (Roadmap)
1. **Mes 1:** Excel avanzado + Introducción a bases de datos y SQL básico/intermedio.
2. **Mes 2:** Introducción a la programación con Python (sintaxis básica, estructuras de datos) y librerías de análisis (`Pandas`).
3. **Mes 3:** Estadística aplicada + Visualización de datos (Matplotlib/Seaborn).
4. **Mes 4:** Herramientas de BI (Power BI o Tableau) + Creación de un proyecto final integrador (portafolio).
